# Chapter 5 — Org admin: viewing and adding users

**Audience:** Organization administrators.  
**Length:** about 2–3 minutes.  
**Start:** Logged in as org admin on the organization page.  
**Prep:** A unique email address for the new user; SMTP ready so the invite can send.

---

## Action script

| Cue | Do this |
|---|---|
| 1 | On the org page, click **View users** (or **View all users** under Recent Users). |
| 2 | On the users page, show the table columns: username/email, full name, email, Status, Manager, Actions. Type a few characters in the search box to filter, then clear. |
| 3 | Click **Create New User**. |
| 4 | Confirm Organization is pre-filled. Under **User role**, select **User** (default path). Fill **First name**, **Last name**; let **Display name** auto-fill or keep the default. Enter **Email / Username**. |
| 5 | Leave **Email a link so the user sets their own password** checked (password fields stay hidden). |
| 6 | Click **Create User**. |
| 7 | Back on the user list, show the new row and any success flash about email sent. |
| 8 | Scroll briefly to **Quick Add User** at the bottom; mention it as the fast alternative, then stop (no need to submit it). |

---

## Narration

**Cue 1.** Open View users to see everyone in your organization.

**Cue 2.** The table lists each person, their status, whether they are a manager, and actions. Use the search box to find someone quickly.

**Cue 3.** Click Create New User for the full form.

**Cue 4.** The organization is already set. Choose the User role for a normal member. Enter first name, last name, and email — the display name fills in for you, and the email is also their username.

**Cue 5.** Leave the invite checkbox on so they receive a link to set their own password. You do not need to invent a temporary password.

**Cue 6.** Click Create User.

**Cue 7.** The new person appears in the list, and they get the invite email we covered in Chapter 1.

**Cue 8.** At the bottom of this page, Quick Add User is a shorter form for the same kind of invite. Use Create New User when you want the role choice; use Quick Add when you only need a regular user fast.
