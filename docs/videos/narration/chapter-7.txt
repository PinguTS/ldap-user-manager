When someone cannot get back into their account, open New password on their row.

Prefer Email password reset link. That sends them the same kind of email as forgot password — they choose a new password themselves. Click Reset.

Confirm the link was sent. They finish the flow from their inbox, as in Chapter 2.

Use Edit to fix a name or email. Save changes when you are done. Leave the optional password fields empty unless you truly need to set a password by hand.

To remove someone permanently, use Delete on the full user list — not the Recent Users shortcuts on the organization overview.

Read the warning, then confirm Delete Account. This cannot be undone.

The account is gone from your organization. If Delete is disabled, they are still a manager — turn Manager off first, then delete.
