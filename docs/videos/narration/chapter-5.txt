Open View users to see everyone in your organization.

The table lists each person, their status, whether they are a manager, and actions. Use the search box to find someone quickly.

Click Create New User for the full form.

The organization is already set. Choose the User role for a normal member. Enter first name, last name, and email — the display name fills in for you, and the email is also their username.

Leave the invite checkbox on so they receive a link to set their own password. You do not need to invent a temporary password.

Click Create User.

The new person appears in the list, and they get the invite email we covered in Chapter 1.

At the bottom of this page, Quick Add User is a shorter form for the same kind of invite. Use Create New User when you want the role choice; use Quick Add when you only need a regular user fast.
